Governance

  • Confidence gate — never removes oversight
  • Sparse retrieval hard rule — min 3 lines
  • Cold-start protection — always routes to review
  • High-value invoice override
  • Append-only audit log — cryptographically hashed
  • Full provenance per decision — trace ID reconstructable

Middleware layer

  • FastAPI — async, Python 3.12+
  • Multi-tenant router — JWT per tenant
  • Tool abstraction — typed ERP connectors
  • LangGraph agentic layer — ambiguous invoices
  • Async write-back dispatcher
  • Circuit breakers on all external calls
  • Langfuse hooks — full distributed tracing
